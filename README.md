# MovieApp

MovieApp is a cross-platform mobile app built with **.NET MAUI**. It helps users discover movies, write reviews, and keep track of watched movies.

---

## Features

### Movie Discovery
- Fetch real-time movie information from external databases.
- Search movies by title, director, or genre.
- Suggest similar movies based on genres.

### Personalization
- Mark movies as watched and track your watchlist.
- Rate movies with a five-star system and add personal reviews.

### Theme
- Switch between light and dark modes.
- Save your preferred theme for next time.

### Settings
- Clear reviews, watch history, and cache.
- Sign out to reset user data.

---

## Technical Details
- Built with **.NET MAUI** for cross-platform support.
- Uses **AppShell** for navigation and **NavigationPage** for onboarding.
- Stores simple settings in **Preferences** and sensitive data in **SecureStorage**.
- Designed with **XAML**, using **FlexLayout** and **Grids** for responsive UI.
